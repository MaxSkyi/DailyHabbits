# Скріншоти додатку

Розмістіть у цій папці ваші скріншоти зі збереженням наступних назв:

1. `main-dashboard.png` — Головний екран зі списком звичок та прогрес-баром
2. `habit-modal.png` — Модальне вікно створення/редагування звички
3. `heatmap.png` — Річна теплова карта активності (Heatmap)
4. `settings.png` — Вікно налаштувань, сповіщень та оновлень
