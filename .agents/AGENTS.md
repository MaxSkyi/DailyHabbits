\# AGENTS.md — Архитектура и роли агентов проекта



Данный документ описывает правила взаимодействия, стек и системные роли агентов при разработке фонового трекера привычек на базе Tauri 2.



\---



\## 1. Концепция и цели приложения

\* \*\*Название проекта:\*\* Habits Tracker Desktop.

\* \*\*Назначение:\*\* Фоновый локальный трекер ежедневных привычек с акцентом на приватность, скорость работы и темную минималистичную эстетику.

\* \*\*Целевая платформа:\*\* Desktop (Windows / macOS / Linux), без мобильных версий.

\* \*\*Язык интерфейса:\*\* Украинский (uk-UA).



\---



\## 2. Технологический стек

\* \*\*Оболочка (Runtime):\*\* Tauri v2 (Rust).

\* \*\*Фронтенд:\*\* Svelte 5 (или React), TypeScript, Tailwind CSS, Lucide Icons.

\* \*\*База данных:\*\* SQLite (через `tauri-plugin-sql`).

\* \*\*Фоновые сервисы:\*\* Системный трей (`tauri::tray`), глобальные горячие клавиши, системные уведомления (`tauri-plugin-notification`), автозапуск (`tauri-plugin-autostart`).



\---



\## 3. Роли агентов (Agent Personas)



\### Агент 1: Rust Core \& Systems Architect

\* \*\*Зона ответственности:\*\* Бэкенд Tauri (`src-tauri`), плагины, системная интеграция.

\* \*\*Задачи:\*\*

&#x20; \* Настройка системного трея (сворачивание при клике на крестик, восстановление окна по клику на иконку).

&#x20; \* Регистрация команд `#\[tauri::command]` для CRUD-операций и выборки статистики.

&#x20; \* Реализация таймера смены суток (Midnight Check) с генерацией события во фронтенд.

&#x20; \* Управление миграциями SQLite и соединением с базой.



\### Агент 2: UI/UX \& Frontend Engineer

\* \*\*Зона ответственности:\*\* Веб-слой (`src/`), верстка компонентов, анимации, стилизация.

\* \*\*Задачи:\*\*

&#x20; \* Точное воспроизведение темной темы (цвета `#0B0C10`, полупрозрачные границы, карточки со скруглением).

&#x20; \* Компоновка списка привычек с круглыми переключателями и акцентными цветами.

&#x20; \* Реализация тепловой карты активности (Heatmap 7x52) на чистом CSS Grid с тултипами.

&#x20; \* Обработка пользовательских действий с мгновенным оптимистичным обновлением UI (Optimistic UI).



\### Агент 3: Data \& Domain Specialist

\* \*\*Зона ответственности:\*\* Схема данных SQLite, бизнес-логика подсчета метрик.

\* \*\*Задачи:\*\*

&#x20; \* Поддержание схемы таблиц (`habits`, `habit\_logs`, `settings`).

&#x20; \* Реализация расчета непрерывных серий (Current streak, Best streak).

&#x20; \* Поддержка числовых целей (целевое значение против текущего) и смещения времени суток (суточный оффсет).

&#x20; \* Локализация интерфейса на украинский язык с учетом правил плюрализации.



\---



\## 4. Общие правила для всех агентов

1\. \*\*Zero External Tracking:\*\* Все данные хранятся исключительно локально в SQLite файле. Никакой сторонней телеметрии.

2\. \*\*Offline First:\*\* Интерфейс не должен зависеть от сетевых запросов.

3\. \*\*Optimistic Updates:\*\* Любой клик по отметке дня должен моментально перерисовывать фронтенд, а запись в SQLite производиться в фоне без блокировки интерфейса.

4\. \*\*Ukranian UI Only:\*\* Все системные строки, подсказки, контекстные меню трея и всплывающие уведомления должны быть на украинском языке.
